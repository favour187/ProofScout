ProofScout · Privacy

Nothing you inspect is sent to us.

Short version: ProofScout analyzes the page on your device. It has no analytics, advertising, user account, remote AI service or page-content server.

Information accessed

The browser assistant reads visible page text, the current URL and page structure only to provide its safety, URL, accessibility and bug checks. This access happens locally inside the browser.

Information collected or transmitted

ProofScout does not collect, sell, transmit or share browsing history, page content, credentials, identity information or inspection results. It does not use analytics or tracking SDKs.

Local storage

The web application may save cases and preferences in browser storage when the user explicitly chooses to save them. This information remains on the user's device and can be deleted by the user. The page assistant does not create a remote profile.

Permissions

Access to HTTP and HTTPS pages is required so the assistant can appear on and inspect the page the user is viewing. ProofScout cannot run on protected browser-internal pages. The extension does not request access to downloads, browsing history, cookies, passwords, location, camera, contacts or payments.

Third parties

No page content is sent to third parties. Browser-provided speech synthesis may be used when the user asks Scout to read a result aloud; behavior depends on the user's browser and operating system.

Security limitations

ProofScout provides screening and developer guidance, not a guarantee that a page is legitimate, secure or bug-free. Users should independently verify organizations and seek qualified support where money, identity or safety may be at risk.

Contact

Questions can be opened through the public project repository: GitHub Issues.
